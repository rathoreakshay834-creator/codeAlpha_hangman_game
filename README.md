# CodeAlpha Hangman Game

A fun text-based Hangman game built using Python. This version includes multiple categories, difficulty levels, hints, score tracking, and replay support.

## Features

- Multiple word categories
  - Animals
  - Countries
  - Programming
  - Fruits
- Difficulty levels: easy, medium, hard
- Random word selection
- Hint system
- Score tracking
- Best score saving
- Hangman drawing progress
- Replay option
- Console-based gameplay

## Technologies Used

- Python
- Random module
- Lists and dictionaries
- Loops and conditionals
- String operations
- File handling

## How to Run

1. Install Python 3 on your system.
2. Open the project folder in VS Code.
3. Open a terminal in that folder.
4. Run the following command:

```bash
python hangman.py
```

## Gameplay

- Choose a category
- Select a difficulty level
- Guess letters one at a time
- Type `hint` if you need a clue
- Try to complete the word before the hangman is fully drawn
